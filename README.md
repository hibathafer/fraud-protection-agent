# وكيل حماية من الاحتيال — Fraud & Scam Protection Agent

وكيل ذكي يعترض **تحويلات المحافظ بالعراق** قبل تنفيذها: يكشف ملامح الاحتيال
بقواعد شفافة قابلة للتدقيق، ويشرح الخطر للمستخدم بلهجة عراقية، ويترك **القرار
أخيراً للمستخدم**. مبني لتحدي Agentic AI Challenge Iraq (موضوع 01).

## شنو يسوي بالضبط

1. **كشف قبل التحويل** — محرك قواعد Python (`src/detection/`) يعطي
   `allow` / `warn` / `hold` مع نقاط وأسباب مكتوبة بالعربي (كل سبب سطر واحد).
2. **توعية بلهجتنا** — رسالة من ثلاثة أجزاء: شنو المريب، شنو المحتال غالباً
   يكول بعدها، وشنو تسوي. القوالب تشتغل بدون نت، و`gemini-3.6-flash`
   اختياري لصياغة أقرب للكلام العراقي.
3. **قرار المستخدم دائماً** — حتى بعد أقوى تحذير، خيار "أكمل" مفتوح
   (مع فترة تهدئة 10 ثوانٍ)، وكل تدخل ينكتب بسجل تدقيق.

> ⚠️ **بيانات 100% اصطناعية** — لا بيانات حقيقية بأي مكان، والـ PIN ما
> يتسجل ولا ينرسل لأي نموذج.

## المتطلبات

- Python **3.11+** (مجرَّب على 3.14) — ويندوز أو غيره
- متصفح — بدون أي اتصال إنترنت للقوالب والكشف
- (اختياري) مفتاح `GEMINI_API_KEY` لتفعيل صياغة الـ LLM

## التشغيل خطوة بخطوة (ويندوز)

```powershell
# 1) نسخ المشروع
git clone https://github.com/hibathafer/fraud-protection-agent.git
cd fraud-protection-agent

# 2) بيئة معزولة + مكتبات
py -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt

# 3) ملف .env بالجذر (اختياري — بدونه كل شي يشتغل بالقوالب):
#    GEMINI_API_KEY=مفتاحك_هنا
#    COACH_MODE=template
#    GEMINI_MODEL=gemini-3.6-flash

# 4) تشغيل الخادم
python -m uvicorn src.api.main:app --reload
```

ثم افتحي: **http://localhost:8000**

أوامر مهمة:

```powershell
python -m pytest -q          # الاختبارات (294 — بدون نت وبدون مفتاح)
python -m src.demo_check     # فحص جاهزية الديمو (PASS/FAIL بالإنجليزي)
```

## وضع التوعية `COACH_MODE`

يُضبط من ملف `.env` (أو متغير البيئة) — يُقرأ وقت تشغيل الخادم:

| القيمة | السلوك |
|--------|--------|
| `template` | **الافتراضي** — قوالب عربية جاهزة، بدون نت وبدون مفتاح |
| `llm` | يفعّل Gemini لصياغة الرسالة — وأي فشل/مهلة (10 ثوانٍ) يرجع للقالب تلقائياً |
| `auto` | مثل `llm` عملياً: يشتغل إذا المفتاح موجود، وإلا القوالب |

- اسم الموديل: `GEMINI_MODEL` (الافتراضي `gemini-3.6-flash`).
- بدون مفتاح النظام كامل يشتغل — تغيير الوضع **مو شرط تشغيل**.

## هيكل المجلدات

```
src/
  api/           واجهة FastAPI (كل النقاط)
  detection/     محرّك الكشف — القرار منه حصراً (قواعد Python)
  coaching/      قوالب التوعية + طبقة LLM اختيارية
  agents/        Intake: نص حر + Dialogue: سؤال ≤ 50 كلمة + Training: وضع تدريب
  eval/          التقييم (dev + المعزول) + سيناريوهات الفشل + تقييم القالب llm_eval
  integrations/  محفظة Zain Cash (محاكاة) ومسار التهدئة
web/             الواجهة: HTML + CSS + JS بدون أي framework وبدون CDN
demo/            6 سيناريوهات JSON + سكربت العرض + أسئلة اللجنة
tests/           294 اختباراً (mock فقط — صفر إنترنت)
data/            بيانات اصطناعية + كتالوج الأنماط (لا بيانات حقيقية)
prompts/         صياغات توليد البيانات (منسوخة من ملحق ROADMAP)
docs/            كل التوثيق (تقدم، تقييم، خصوصية، إفصاح، مرجع متطلبات اللجنة)
```
