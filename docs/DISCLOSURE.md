## 5. البيانات ومصادرها

- **100% بيانات اصطناعية** مولّدة داخل المشروع (توليد هجين: LLM + قواعد Python،
  `random.seed(42)` للتكرار) — **لا توجد أي بيانات حقيقية** (لا أرقام، لا أسماء،
  لا أرصدة، لا أرقام هواتف حقيقية) في أي ملف أو قاعدة أو سجل.
- **الأنماط (كتالوج `data/scam_catalogue.json` — 8 أنماط):** مبنية على أنواع
  احتيال معروفة ومنتشرة بتسوق التحدي (تخطيط T2)؛ **التوسعة** تتم من:
  - مقابلات قصيرة تقوم بها هبو (3–5 أشخاص) → `docs/user_research.md` ✋ (مهمة يدوية)
  - تحذيرات رسمية منشورة عن احتيال المحافظ بالعراق → توثيق روابطها بـ
    `docs/user_research.md` ✋ (مهمة يدوية)
- **الرمز السري PIN:** لا يُسجَّل ولا يُخزَّن ولا يُرسل لأي نموذج إطلاقاً.
- **`.env`:** مُدرَج بقائمة `.gitignore` (تتجاهله Git ولا يُرفع أبداً)، ولا يُفتح ولا يُطبع ضمن أي رد أو ملف.
