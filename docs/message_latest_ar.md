> `docs/PROGRESS.md` (سجل المهام) و`docs/summary_latest_ar.md` (أحدث ملخص).

## شنو طلبتِ وشنو سوينا؟

طلبتِ: يحاكي الديمو إنو التحويل يمر من **محفظة Zain Cash** الحقيقية،
والوكيل يعترض الطلب قبل ما ينفّذ، وبناءً على القرار:

- **allow (سماح)** → التحويل ينفّذ فوراً ويطلع **إيصال** برقم `ZC...`
- **warn أو hold (تنبيه/تحذير)** → التحويل **يتوقف مؤقتاً**، تطلع نافذة
  التهدئة **10 ثواني**، وبعدها تختارين:
  - «أكمل التحويل» → ينفّذ ويطلع الإيصال
  - «إلغاء التحويل» → ما ينفّذ شي (هذا الزر شغّال من أول لحظة)

وسويت الواجهة بستايل **Zain Cash الحديث (بنفسجي عميق + كروت بيضاء)**: بطاقة تحويل، رقم المرسل،
رقم المستلم، المبلغ، ورمز PIN السري — عشان الحكام يشوفون الموضوع واضح.

## كيف أجرّبه بنفسي؟

1. شغّلي السيرفر عادي:
   ```
   python -m uvicorn src.api.main:app --reload
   ```
2. افتحي `http://127.0.0.1:8000/` → لازم تشوفين بطاقة بنفسجية/بيضاء مكتوب عليها Zain Cash
3. **تحويل عادي**: اختر سيناريو «تحويل عادي» + رقم مستلم `07855550001`
   + مبلغ `100000` + PIN `1234` → يطلع إيصال فوراً ✅
4. **احتيال**: اختر سيناريو «احتيال جائزة» → نافذة تحذير + عداد 10 ثواني،
   بعدين كمّلي أو ألغي
5. افتحي صفحة **السجل** → في عمود جديد اسمه **«الحالة»**:
   `pending` (معلّق) / `completed` (نُفّذ) / `cancelled` (ملغى)

## ملاحظات مهمة

- **الـ PIN ما ينحفظ بأي مكان** — لا بالسجل ولا باللوقات ولا ينرسل للـ LLM.
  مختبر بـ اختبار خاص.
- **الإيصال ما يكشف رقمك كامل** — مثلاً `0785****001`
- القرار **من القواعد فقط** — نفس الكود القديم بالضبط، المحفظة تنفّذ القرار مو تغيّره.
- لو تبي تغيّرين ألوان المحفظة: `web/style.css` تحت قسم Zain Cash
  (المتغيرات `--zain-purple` و `--zain-purple-light` بقسم Zain Cash).
