# شرح المشروع بالتفصيل

## الفكرة العامة

مشروع **Fraud & Scam Protection Agent** لمحفظة موبايل بالعراق. الفكرة بسيطة:

> قبل ما المستخدم يكمل تحويل مالي، النظام يقيّم العملية. إذا فيها علامات احتيال، يوقف الشاشة ويشرح للمستخدم **بلهجة عراقية**: شنو المريب، وليش، وشنو المحتال غالباً يكول بعدها. المستخدم يقرر (يكمل أو يلغي)، وكل شي ينسجل.

## طبقة الكشف (Detection Engine)

### القواعد التسع:

| القاعدة | الشرط | النقاط |
|---------|-------|-------|
| `NEW_RECIPIENT` | أول تحويل لهذا المستلم | +20 |
| `YOUNG_RECIPIENT_ACCOUNT` | حساب المستلم عمره < 14 يوم | +15 |
| `AMOUNT_HIGH` | المبلغ > 3 × الوسيط (أو > 300,000 إذا التاريخ قصير) | +25 |
| `BALANCE_DRAIN` | المبلغ ≥ 70% من الرصيد | +15 |
| `ODD_HOUR` | الساعة 0-5 وليست من ساعات نشاطه | +10 |
| `RAPID_SEQUENCE` | ≥ 3 تحويلات خلال 30 دقيقة | +15 |
| `SCAM_PATTERN` | تطابق مع كتالوج الأنماط | +35 |
| `CUMULATIVE_NEW_RECIPIENT` | 3+ تحويلات لنفس المستلم الجديد خلال 7 أيام | +20 |
| `TRUSTED_RECIPIENT` | ≥ 3 تحويلات سابقة على ≥ 14 يوم | -25 |

**النتيجة** = مجموع النقاط، تُقصّ بين 0 و100.

**القرار:**
- `< 30` → **allow**: تمر بدون تدخل
- `30–59` → **warn**: رسالة توعية، المستخدم يكمل بسهولة
- `≥ 60` → **hold**: رسالة + انتظار 10 ثواني + checkbox "فهمت المخاطرة"

### كتالوج الأنماط (8 أنماط):

1. `otp_fake_agent` — موظف مزيف يطلب رمز التحقق
2. `prize_fee` — "ربحت جائزة" + رسوم
3. `safe_account` — "حسابك مخترق، حوّل للحساب الآمن"
4. `fake_job_fee` — وظيفة مقابل رسوم
5. `relative_new_number` — "هذا رقمي الجديد"
6. `advance_payment_seller` — دفعة مقدمة
7. `investment_doubling` — أرباح مضمونة
8. `fake_refund` — استرجاع مبلغ مع رسوم

## طبقة التوعية (Coaching)

### بنية الرسالة (3 أجزاء، ≤ 60 كلمة):

1. **شنو المريب** — من أسباب الكشف
2. **شنو المحتال غالباً يكول بعدها** — من الكتالوج
3. **شنو تسوي** — نصيحة

### اللهجة:
- `شنو` مو `شو`
- `اكو/ماكو`
- `هسه`
- `دز/تدز`
- ممنوع الشامي والمصري

### الترتيب:
1. القالب جاهز دائماً (يشتغل بدون نت)
2. إذا الـ LLM مفعّل: يعيد صياغة القالب
3. إذا فشل الـ LLM: يرجع للقالب

## قواعد صارمة

1. **القرار من قواعد Python فقط** — الـ LLM ما يغيره
2. **ممنوع الكشف يقرأ** `is_scam` / `scam_type` / `case_id`
3. **الإحصاءات من الماضي فقط** — ممنوع تسريب المستقبل
4. **ممنوع قراءة** `data/test_sealed/` إلا بـ `evaluate --final`
5. **كل ميزة لها اختبار pytest**
6. **لا مفاتيح بالكود** — المفتاح من `.env`
7. **لا تشغيل سيرفر بالخلفية** — المستخدم يشغّله بنفسه
