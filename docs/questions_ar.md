# إجابات على أسئلتك

## 1. شلون نشغّله على سيرفر حقيقي (مو بس على جهازي)؟

هذا اسمه **Deployment** (نشر). الخيارات:

| الطريقة | الصعوبة | التكلفة | ملاحظة |
|---------|---------|---------|--------|
| **Render** | سهلة | مجاني البداية | **مستخدَم بالمشروع** — `render.yaml` جاهز بالجذر |
| **Railway** | سهلة | مجاني البداية | بديل سهل للمبتدئين |
| **Vercel** | متوسطة | مجاني | أكثر تعقيداً بـ Python |
| **VPS (مثل DigitalOcean)** | صعبة | ~$5/شهر | تحتاج خبرة لينكس |

- خطوات الرفع على Render بالعربي: `docs/deploy_ar.md`.
- رابط النشر العام **بانتظار تحققك** من طرفك (موعد التسليم يحدده).

---

## 2. المتصفح عرض JSON بدل الواجهة — لسه موجودة هالمشكلة؟

**صارت بأول المشروع وانحلت من زمان.** المشكلة وقتها كانت: الـ endpoint الجذر `/`
كان معرّف قبل الـ web mount فياخذ الأولوية.

**الوضع الحالي (كيف تتحققين):**

| الرابط | المتوقع |
|--------|---------|
| `http://localhost:8000/` | الواجهة (index.html) |
| `http://localhost:8000/api` | JSON — فهرس الـ 16 نقطة |
| `http://localhost:8000/docs` | OpenAPI — كل نقاط API |
| `http://localhost:8000/log.html` | واجهة السجل |

السبب الأصلي موثّق: الـ API كله صار تحت `/api` (root معرّف بـ `@app.get("/api")`)،
و`/` تخدم مجلد `web/` بـ `app.mount("/", ... html=True)`.

---

## الخلاصة

- الواجهة والـ API يشتغلون معاً بدون تعارض — اختبريهم بالروابط أعلاه.
- النشر متاح جاهزاً (`render.yaml` + `docs/deploy_ar.md`) — رفعه شغلك إنتِ.
- أي مشكلة تشوفينها وقت التشغيل — انسخي رسالة الخطأ وجيبيلي إياها.
