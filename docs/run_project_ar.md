# كيف تشغّل المشروع (أمر واحد)

> أنا (الوكيل) ما أقدّر أشغّل السيرفر بنفسي — قاعدة المشروع تمنعني من تشغيل
> أي عملية بالخلفية، والتشغيل عليكِ. هذي الخطوات بالعربي:

## الخطوة 1: افتحي التيرمنل بـ VS Code
(من القائمة: Terminal ← New Terminal، أو الضغط `Ctrl` + `` ` ``)

## الخطوة 2: اكتبي أمر التشغيل

```
python -m uvicorn src.api.main:app --reload
```

لازم تشوفي شي زي:

```
INFO:     Uvicorn running on http://127.0.0.1:8000
```

> إذا طلع لك `INFO: Application startup complete` — يعني كلشي شغّال ✅
> أول تشغيل: القاعدة تتعبّى تلقائياً ببيانات dev (20 مستخدم) — انتظري ثانيتين.

## الخطوة 3: افتحي المتصفح

```
http://127.0.0.1:8000/
```

لازم تشوفين: بطاقة تحويل **بنفسجية/بيضاء** مكتوب عليها **Zain Cash**.

جرّبي:
1. سيناريو «تحويل عادي» → مبلغ `100000` → PIN `1234` → إيصال فوري
2. سيناريو «احتيال جائزة» → نافذة تحذير + عداد 10 ثواني → كمّلي أو ألغي
3. صفحة **السجل** → عمود «الحالة»

## الخطوة 4: الإيقاف
ارجعي للتيرمنل واضغطي `Ctrl + C`

## إذا طلعت مشكلة

| المشكلة | الحل |
|---------|------|
| `'uvicorn' is not recognized` | استخدمي `python -m uvicorn ...` (كما بالأعلى) |
| الصفحة فاضية | انتظري ثانية واضغطي refresh |
| تبين رابط لغيرك بنفس الشبكة | `python -m uvicorn src.api.main:app --host 0.0.0.0` وبعدها شوفي IP بـ `ipconfig` (الشرح بـ `docs/sharing_guide_ar.md`) |
| تبين رابط عام من الإنترنت | شوفي `docs/deploy_ar.md` (Render) |
