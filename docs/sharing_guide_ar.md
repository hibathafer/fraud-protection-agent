# شلون تعرض التطبيق على أشخاص غيرك (غير localhost)

---

## الطريق 1: نفس الشبكة (الأسهل) ✅

إذا الأشخاص متصلين بنفس الواي فاي (نفس البيت/المكتب):

### الخطوات:

**1. أطفئي السيرفر الحالي** بـ `Ctrl+C`

**2. شغّليه يقبل اتصالات خارجية:**
```
python -m uvicorn src.api.main:app --host 0.0.0.0 --port 8000
```

**3. شوفي IP جهازك** — اكتبي بـ cmd:
```
ipconfig
```
دور على **IPv4 Address** — شي مثل `192.168.1.10`

**4. أعطيهم الرابط:**
```
http://192.168.1.10:8000
```
(استبدلي الرقم بمعدل جهازك)

**5. جدار الحماية (Firewall):** إذا طلع لك طلب أول مرة، اضغطي **Allow**.

> ✅ الأشخاص لازم يكونون على نفس الشبكة
> ✅ مجاني وفوري

---

## الطريق 2: نشر على سيرفر مجاني (للعرض من أي مكان) 🌐

إذا تبين يفتحونه من أي مكان بدون نفس الشبكة:

### خيارات مجانية:

| المنصة | الصعوبة | ملاحظة |
|--------|---------|--------|
| **Render.com** | سهلة | مجاني مع نوم بعد عدم الاستخدام |
| **Railway.app** | سهلة | مجاني للبداية |
| **ngrok** (مؤقت) | سهلة جداً | رابط مؤقت لساعة — ممتاز لعرض سريع |

### أسرع طريقة مؤقتة (ngrok):
```
ngrok http 8000
```
يعطيك رابط عام مثل `https://abc123.ngrok-free.app` — ترسلينه لأي أحد.

## ⚠️ تنبيهات مهمة

1. **لا تنشرين الكود على GitHub بدون فحص** — `.env` موجود بـ `.gitignore` وهذا صحيح، تأكدي قبل الرفع
2. **بيانات الاختبار المعزولة** (`data/test_sealed/`) ما تنعرض — النظام ما يقرأها إلا بـ `--final`
3. **الأفضل للعرض الرسمي:** الطريق 1 (نفس الشبكة) أثناء العرض، والقرار النهائي في T10
