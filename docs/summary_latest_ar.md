## شلون تعرض التطبيق على غيرك

### الطريق 1: نفس الشبكة (الأسهل) ✅
1. أطفئي السيرفر بـ `Ctrl+C`
2. شغّليه:
   ```
   python -m uvicorn src.api.main:app --host 0.0.0.0 --port 8000
   ```
3. شوفي IP جهازك: اكتبي `ipconfig` بـ cmd ودور على **IPv4 Address**
4. أعطيهم الرابط: `http://192.168.1.10:8000` (بديلة رقمي بمعدل جهازك)
5. إذا طلب firewall: اضغطي **Allow**

> لازم يكونون متصلين بنفس الواي فاي

### الطريق 2: من أي مكان (مؤقت) 🌐
- **ngrok**: يعطيك رابط عام مؤقت:
  ```
  ngrok http 8000
  ```
  ترسلين الرابط لأي أحد من أي مكان.

### الطريق 3: نشر دائم ✅ (جاهز من T10)
- Render.com: `render.yaml` جاهز بالمشروع — الرفع بحسابك، والرابط العام معلّق بتحقّق بسيط من طرفك (انظر `docs/PROGRESS.md`).
