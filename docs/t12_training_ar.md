# T12 — وضع التدريب (Training Mode) — شرح وطريقة التحقق

> افتحي هذا الملف بـ VS Code لقراءة الشرح كامل بالعربي.
> هذي آخر مهمة بالخارطة الطريق (T0 → T12) — مبروك! 🎉

## شنو صار بهالمهمة؟

زدنا **صندوق «وضع تدريب»** بصفحة الرئيسية: محادثة تعليمية وهمية تلعب فيها
الشخصية دور «موظف الدعم» (أو رسائل فاتورة عادية)، والمستخدمة تتدرب تفرّق
بين الإشارات — كل خطوة تختار: **«هذا احتيال»** أو **«أكمل»** — وبالنهاية
**تقييم بسيط + تعليق باللهجة العراقية**.

## كيف يشتغل؟ (ببساطة)

1. **سيناريوهات مكتوبة داخل الكود** (`src/agents/training.py`) — بيانات
   اصطناعية 100%، ما تقرأ أي بيانات مستخدمين ولا أي ملف:
   - `fake_support`: مكالمة من «الدعم الفني» — أول سطر عادي، وبعدها ضغط
     وطلب رمز وسرّية (الصواب: كمّل، ثم احتيال × 3).
   - `invoice_notice`: فاتورة عادية × 4 (الصواب: كمّل كلها) — تعلّم ما تبالغ
     بالاشتباه.
2. **كل سطر له حكم `is_scam` مكتوب يدوياً** — والتقييم **بايثون** يقارن
   إجاباتك بالحكم: صح/غلط لكل سطر، نسبة مئوية، حكم (ممتاز/زين/متوسط/ضعيف)،
   وتعليق باللهجة يذكر غلطاتك بالتحديد.
3. **الـ LLM اختياري ومحصور بدور «الصوت» بس**: يعيد صياغة السطر باللهجة
   العراقية داخل برومت ثابت، **الحكم ما يشوفه ولا يقرّر منه**. أي خروج مرفوض
   (أرقام جديدة، أكثر من 50 كلمة، خطأ شبكة) → **السطر الأصلي كما هو**.
   بدون مفتاح وبدون نت، السيناريو كله يشتغل عادي.

## الأمان: ثلاث ضمانات مثبتة بالاختبارات

| الضمانة | الاختبار |
|---------|----------|
| **معلن «تدريب» بكل رد** + ما فيه أي حقل قرار/درجة بالردود | `test_start_default_scenario_is_labelled_training` + `test_training_response_has_no_decision_fields` |
| **صفر لمسة لقاعدة البيانات**: endpoint بدون `Depends(get_db)` أصلاً — لا يقرأ مستخدمين ولا يكتب `decision_log` ولا `chat_turns` | `test_training_never_touches_database` |
| **ما يسرّب الإجابة الصحيحة**: أحكام `is_scam` لا تُرسل للواجهة قبل ما تجاوب | `test_scenario_labels_never_leak_to_client` |

وفوقها: **ما فيه نص حر أصلاً** بالتدريب (الإجابات قيم جاهزة `flag`/`continue`
يحدّدها Pydantic) → **مسار Prompt Injection غير موجود من الأساس**.

### 2. تجربة يدوية بالواجهة
```powershell
python -m uvicorn src.api.main:app --reload
```
- افتحي `http://127.0.0.1:8000` وانزلي لصندوق **«وضع تدريب»** (شارة بنفسجية)
- اختر سيناريو «مكالمة من الدعم الفني» واضغطي **ابدأ التدريب**
- كل سطر: قرري — **«هذا احتيال»** أو **«أكمل»** (4 خطوات)
- بالنهاية تشوفين: `4/4 (100%)` + حكم + تعليق باللهجة
- جرّبي السيناريو الثاني «رسائل فاتورة» وعلّمي الكل احتيال — بتشوفين
  الغلطة: «علّمت احتيال على رسالة عادية...»
- زر **«تدريب جديد»** يعيد التشغيل

### 3. ملاحظات للديمو
- الشارة «وضع تدريب» والسطر «محادثة تعليمية وهمية» **دائماً ظاهرین** —
  مفيش أي لبس إنها محفظة حقيقية.
- التدريب **ما ينشئ إيصال، ما يسجّل قرار، ما يمسّ السجل** — افتحي بعده
  صفحة السجل وبيكون فاضي (أو زي ما هو).
- بدون مفتاح: السيناريو كامل يشتغل (السطر الأصلي). مع `COACH_MODE=llm`:
  سطر المحادثة يتولّد باللهجة مع الحفاظ على نفس المعنى.

## قرار اللجنة إذا سألت: «هذا سبب يوقف تحويل؟»

لا — **التدريب مستقل تماماً عن محرّك الكشف**: نقطة API بدون أي اتصال
بقاعدة البيانات، والمسار الوحيد اللي يغيّر قرار تحويل هو معاملة تجارية
(centerpiece T1–T9). التدريب نشاط تعليمي للمستخدم، معلن ومفصول.
