# ملخص T5 — الواجهة

> أرقام هالملف مؤرخة وقت تسليم T5 — إجمالي الاختبارات الحالي: **294** (`docs/PROGRESS.md`).

## شنو سويناه

### 1. صفحات الويب (`web/`)
- **`index.html`** — شاشة المحفظة الرئيسية:
  - اختيار المستخدم من قائمة منسدلة
  - نموذج تحويل (مستلم، مبلغ، ملاحظة، رسالة وصلتك)
  - قائمة "جرّب سيناريو جاهز"
  - نافذة تحذير منبثقة (modal) فيها:
    - شارة القرار (لون + كلمة: تنبيه / تحذير شديد)
    - الأسباب كنقاط
    - رسالة التوعية مع وسم المصدر (قالب / LLM)
    - نص "العملية لم تكتمل بعد"
    - زرّان: إلغاء التحويل (أحمر) وأكمل التحويل (أخضر)
    - بحالة hold: مربع "فهمت المخاطرة" + عداد تنازلي 10 ثواني
  - رسالة نجاح إذا القرار allow

- **`log.html`** — جدول السجل:
  - أعمدة: الوقت، المستخدم، النقاط، القرار، النمط، الاختيار
  - فلاتر حسب القرار والمستخدم
  - زر تصدير

- **`results.html`** — نتائج التقييم:
  - مؤشرات (Recall, Precision, FPR, عدد المعاملات)
  - مصفوفة الالتباس

- **`style.css`** — تصميم RTL بإطار هاتف، ألوان بـ CSS variables، بدون CDN

- **`app.js`** — JavaScript عادي:
  - تحميل المستخدمين والسيناريوهات
  - إرسال النموذج وعرض النتيجة
  - عداد تنازلي لحالة hold
  - تحميل السجل والنتائج

### 2. السيناريوهات الجاهزة (`demo/`)
- **`normal_transfer.json`** — تحويل عادي (allow)
- **`prize_scam.json`** — احتيال جائزة (hold)
- **`otp_scam.json`** — احتيال OTP (hold)

### 3. تحديثات الـ API (`src/api/main.py`)
- إضافة `GET /api/demo_scenarios` — يقرأ ملفات `demo/*.json`
- خدمة صفحات الويب من مجلد `web/` عبر `StaticFiles`

### 4. الاختبارات (`tests/test_web.py`)
- 7 اختبارات جديدة:
  - الصفحات ترجع 200
  - CSS و JS متوفرين
  - السيناريوهات الجاهزة صالحة
