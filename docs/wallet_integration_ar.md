# تكامل محفظة Zain Cash (T5b) — شرح بسيط

> أرقام هالملف مؤرخة وقت تسليم T5b — إجمالي الاختبارات الحالي: **294** (`docs/PROGRESS.md`).

> المطلوب جاي من طلب هبو: نحاكي إن الديمو يشتغل من داخل محفظة Zain Cash
> الحقيقية — الطلب ينعترض قبل التنفيذ، وإذا الكشف صادف تحذير ما ينفّذ
> التحويل ويستنى قرار المستخدم.

## الفلو (المسار) بالعربي البسيط

```
المستخدمة تعبّي النموذج (رقم، مبلغ، PIN، رسالة)
        │
        ▼
POST /api/wallet/transfer          ← الوكيل يعترض الطلب هنا
        │
        ├─ 1) كشف بالقواعد (engine)  ← القرار من القواعد فقط
        ├─ 2) توعية باللهجة (coach)
        ├─ 3) تسجيل بكل التفاصيل بجدول السجل
        │
        ├─ allow    → تنفيذ فوري عبر المحفظة الوهمية → إيصال ZC...
        │
        └─ warn/hold → التحويل يتعلّق + فترة تهدئة 10 ثواني
                       وينتظر قرار المستخدم:
                            POST /api/choice
                             ├─ continue → ينفّذ ويطلع إيصال
                             └─ cancel   → يلغي ويسجّل "ملغى"
```

| الملف | شنو يعمل |

## قواعد مهمة مطبّقة

1. **القرار من القواعد فقط** — نفس دالة `_assess_and_log` القديمة بالضبط
   (profile → engine → coach → سجل). المحفظة تنفّذ القرار بس، ما تغيّره.
2. **الـ PIN خصوصي**: ما ينكتب بالسجل، ما ينرسل للـ LLM، ما ينطبع بأي رد،
   ويبقى بذاكرة العملية حتى تنتهي ثم ينسى. (مختبر بـ `test_wallet_pin_is_never_logged_nor_returned`)
3. **الإيصال ما يكشف الأرقام كامل**: مثلاً `0785****001`.
4. **كلشي يتسجل**: القرار، السبب، رسالة التوعية، اختيار المستخدم،
   و`final_status` (شنو صار بالآخرة بالإيصال).
5. **المستخدمة تكدر تلغي بأي لحظة** — فترة التهدئة 10 ثواني تسوى زر
   "أكمل" بس، زر "إلغاء" شغّال دائماً.

## كيف تجرّبينه بنفسك (خطوة خطوة)

1. شغّلي السيرفر عادي:
   ```
   python -m uvicorn src.api.main:app --reload
   ```
2. افتحي `http://127.0.0.1:8000/` — لازم تشوفين بطاقة تحويل بنفسجية/بيضاء
   مكتوب عليها Zain Cash.
3. **جرّب تحويل عادي**: اختر سيناريو "تحويل عادي"، تعبّي رقم مستلم جديد
   مثل `07855550001` ومبلغ `100000` وPIN `1234` → لازم يطلع إيصال
   `ZC...` (نجاح فوري).
4. **جرّب احتيال**: اختر سيناريو "احتيال جائزة" → لازم تفتح نافذة التحذير،
   وعدّاد 10 ثواني، وبعدها:
   - "أكمل التحويل" → ينفّذ ويطلع إيصال ويتسجّل `completed`
   - "إلغاء التحويل" → ما ينفّذ شي ويتسجّل `cancelled`
5. افتحي صفحة **السجل** → لازم تشوفين عمود "الحالة" جديد
   (pending / completed / cancelled).

## ملاحظات تقنية بسيطة

- الألوان قابلة للتعديل من `web/style.css` (المتغيرات `--zain-purple`
  و `--zain-purple-light` بأول قسم Zain Cash) — الحالي: `#5b1382` بنفسجي عميق.
- الطلب المعلّق يتخزّن **بذاكرة السيرفر** (ما بملف ولا بقاعدة) — إذا السيرفر
  تعبّد و restarted، تكرّر الطلب من الأول. مناسب للديمو.
- البيانات كلها اصطناعية، وما عندنا أي اتصال حقيقي مع Zain.
- `pytest` = **154 اختبار كلها تنجح**.
