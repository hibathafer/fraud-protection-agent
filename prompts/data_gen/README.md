# prompts/data_gen/ — صياغات توليد البيانات (T3)

> منسوخة **حرفياً** من `ROADMAP.md` (الملحق ب) — "نقطة البداية" المستعملة
> بتوليد البيانات الهجين بـ T3 (LLM + Python).

## الملفات

| الملف | الاستعمال |
|-------|-----------|
| `users_spec.txt` | مواصفات المستخدمين الـ 30 (٢٠ dev + ١٠ test) |
| `scam_messages.txt` | رسائل الاحتيال لكل نمط من الـ 8 بالكتالوج |
| `benign_notes.txt` | ملاحظات التحويل البريئة |

## ملاحظة صدق (مهم)

- هذي صياغة **البداية الموثقة** بالخارطة الطريق. أثناء التشغيل الفعلي بـ T3
  ممكن تكون قيمت N أو صياغات بسيطة عُدّلت يدوياً — **ما صار لها تسجيل كامل**.
- المخرجات الفعلية المحفوظة موجودة بـ `data/synthetic/` (CSV) وبها كل شي
  يمكن مراجعته (`docs/data_review.md`).
- البذورة مثبتة `random.seed(42)` فأي توليد جديد يتكرر بنفس النتيجة.
